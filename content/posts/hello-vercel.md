这是博客的第一篇文章。你可以把这里替换成自己的内容，也可以在 `content/posts` 目录下继续添加新的 Markdown 文件。

## 为什么选择这个结构

- 页面由 Next.js 静态生成，速度快，部署简单。
- 文章放在仓库里，适合用 Git 管理版本。
- 样式集中在一个 CSS 文件里，后续修改成本低。

## 下一步可以做什么

你可以添加关于页面、分类页、RSS、搜索，或者把文章数据换成远程 CMS。先从简单结构开始，后续再按真实需求扩展。

今天给博客新增了一个 **Prompt Library** 页面，用来集中记录平时常用的 AI Prompt。

之前很多 Prompt 都散落在聊天记录、临时文档或者脑子里，需要用的时候经常要重新写一遍。现在把它们整理到博客里，至少有几个好处：

- **方便复用**：常用 Prompt 可以直接复制，不用每次重新组织语言。
- **方便迭代**：用得不顺手的地方，可以慢慢改成更适合自己的版本。
- **方便分类**：不同场景的 Prompt 可以按用途区分，比如论文阅读、实验报告、数学建模、MARL 文献整理等。
- **方便沉淀**：把 Prompt 当成一种学习和研究工具，而不是一次性的临时文本。

这次先放了一些和当前学习、项目、论文整理相关的 Prompt。重点包括：文章分析、实验报告、数学建模、MARL 文献整理、AI 改写和报错解释。

其中我比较重视的是 **MARL 协同调度文献整理 Prompt**。因为接下来研究方向更偏向医院院内物流机器人系统中的多智能体协同、任务分配、资源协调和全局效率优化，而不是单纯研究路径规划本身。

后面如果遇到新的高频任务，也可以继续把 Prompt 加进去。这个页面暂时不需要做得很复杂，先保证它能解决一个实际问题：让我更快地调用、比较和改进自己的常用 Prompt。

> Prompt Library 本质上是一个个人工作流记录库。它记录的不只是提示词，也是在记录我如何学习、如何整理资料、如何推进项目。

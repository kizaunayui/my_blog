这份笔记原本是一份比较长的 Word 课程整理，内容从强化学习的基本交互语言开始，一路推进到 DQN、Policy Gradient 和 Actor-Critic。为了放进项目研究页，我没有把它处理成纯资料堆叠，而是按算法脉络重新整理为一篇可以顺着读下来的长文；原文中的公式、表格和流程图也按章节顺序保留下来。

强化学习最核心的问题，是智能体如何在环境中通过试错学习策略。它不像监督学习那样直接拿到标准答案，而是在状态、动作、奖励和未来回报之间不断权衡：当前一步要不要贪心，长期收益要不要等待，已有经验要不要复用，策略本身又该如何被评估和改进。

## 强化学习基础：先把交互语言说清楚

强化学习的语言由几个基本对象构成：State 描述环境当前情况，Action 是智能体可以做出的选择，Reward 是环境给出的即时反馈，Return 则把未来奖励一起纳入考虑。Policy 是智能体采取行动的规则，Episode 则是一段从开始到结束的完整交互轨迹。

网格世界是理解这些概念最直接的例子：智能体在棋盘式环境中移动，目标点给出正奖励，陷阱给出负奖励，每一步可能还有轻微惩罚。通过这个模型，可以直观看到策略如何从随机探索逐渐变成稳定路径。

## MDP、价值函数与 Bellman 方程

MDP 是强化学习的数学基石，由状态集合、动作集合、状态转移概率、奖励函数和折扣因子组成。它的核心假设是马尔可夫性：未来只取决于当前状态，而不依赖更早的历史。只要当前状态包含了足够信息，智能体就可以基于当前状态完成决策。

价值函数把“一个状态有多好”或“一个动作有多好”量化出来。State Value 关注从某个状态开始能得到的期望回报，Action Value 则进一步固定当前动作。Bellman 方程把当前价值拆成即时奖励和后续状态价值，是策略评估、策略改进、价值迭代和后续很多算法的共同基础。

## 从有模型到免模型：Monte Carlo 方法

前面的 Bellman 推导默认环境模型已知，也就是状态转移概率和奖励结构可以被写出来。但实际问题里，我们往往并不知道完整模型。Monte Carlo 方法转向从经验中估计价值：让智能体跑完整个 episode，再用实际回报的平均值估计状态或动作价值。

MC Basic 把策略迭代改造成免模型形式：初始化策略，收集回合，估计动作价值，再贪心改进策略。Exploring Starts 通过让每个状态-动作对都有机会作为起点来保证覆盖；ε-Greedy 则通过保留一定随机探索来换取更高的数据利用效率。

## TD、Sarsa 与 Q-Learning

TD 方法介于动态规划和 Monte Carlo 之间。它不需要等到完整 episode 结束，也不需要已知环境模型，而是用当前奖励加上下一个状态的估计值作为目标。相比 MC，TD 可以在线更新；相比纯 Bellman 解析解，它适合 model-free 场景。

Sarsa 和 Q-Learning 都是在 TD 框架下学习 Action Value。Sarsa 是 on-policy：学习的是当前行为策略本身；Q-Learning 是 off-policy：行为策略可以负责探索，而目标策略始终朝向最优动作更新。二者最关键的区别，就是 TD Target 中下一步动作价值的选择方式不同。

## 函数近似、DQN 与策略梯度

当状态空间变大时，用表格保存每个状态或动作价值会失效，于是需要函数近似。线性近似用特征向量表示状态，DQN 则进一步用深度神经网络替代 Q-Table，让网络输入状态并输出各动作的 Q 值。Target Network 和 Experience Replay 都是为了解决训练不稳定、样本相关性过强等问题。

Policy Gradient 换了一个角度：不再先学价值表再间接得到策略，而是直接优化策略参数。REINFORCE 使用完整回报估计梯度，Actor-Critic 则把策略更新和价值评估拆给 Actor 与 Critic 两个部分，兼顾策略学习和价值估计。

## 小结

这份笔记的脉络可以概括为：先用 MDP 与 Bellman 方程定义问题，再用 MC 和 TD 在未知模型中估计价值，随后通过 Sarsa 与 Q-Learning 学习动作价值，最后进入函数近似、DQN 和策略梯度方法。它不是一份最终版教材，更像是把强化学习从“概念能看懂”推进到“算法之间能连起来”的阶段性整理。

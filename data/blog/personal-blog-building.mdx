## 项目背景

我希望搭建一个长期可维护的个人知识型博客，用来沉淀 Prompt 模板、课程复习资料、作品成果和项目研究记录。

## 实现目标

- 顶部导航清晰，入口数量克制。
- 文章系统支持长期扩展。
- 内容中心按四个栏目组织。
- 课程笔记可以绑定 PDF 下载和预览。

## 使用工具 / 技术栈

- Next.js
- Tailwind CSS
- Contentlayer / MDX
- GitHub
- Vercel
- Codex

## 实现过程

先基于现有博客模板保留 MDX 文章系统，再新增 `/articles` 和 `/content` 两组核心路由。内容数据继续放在 `data/blog/*.mdx`，通过 frontmatter 的 `category`、`tags`、`summary` 和 `pdf` 字段驱动页面展示。

## 最终效果

博客形成了“首页 - 文章 - 内容中心 - 关于我”的结构。内容中心下分为 Prompt 模板库、课程复习笔记、作品展示和项目研究四个并列栏目。

## 遇到的问题

原模板的文章路由是 `/blog`，Prompt 页面也是独立数据结构。为了保持旧链接可用，旧路由保留重定向，新内容统一进入 MDX 文章系统。

## 后续优化方向

- 为作品页补充截图和项目链接。
- 为课程笔记上传正式 PDF。
- 增加更多研究笔记和文献阅读记录。

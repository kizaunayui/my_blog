# Kieran Space

我的个人博客，用来记录学习、项目、作品和随笔。

站点地址：https://www.oyzy666.com

## 内容

- 技术学习记录
- 项目研究笔记
- 作品展示
- 个人随笔

## 技术栈

- Next.js
- React
- TypeScript
- Tailwind CSS
- Contentlayer
- Pliny

## 本地运行

yarn install
yarn dev

## 构建检查

yarn lint
yarn build

## 目录说明

- data/blog：文章内容
- data/authors：作者信息
- data/promptsData.ts：Prompt 模板库
- data/contentSections.ts：内容中心栏目配置
- components：组件
- layouts：页面布局
- css：样式文件
- public/static/images：图片资源
- public/music：音乐资源

## 写文章

文章放在 data/blog/。

frontmatter 示例：

title: 标题
date: '2026-06-15'
summary: 文章摘要
category: 文章
tags: ['标签一', '标签二']
draft: false

常用 category：文章、作品展示、项目研究。

## 维护原则

这个博客不是商业官网，也不是纯文档站。

修改时尽量保留深色基调、玻璃拟态、沉浸式背景、内容中心、音乐播放器和个人博客的气质。

不要为了“专业感”把它改成普通模板站。
